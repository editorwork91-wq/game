# CreatorVerse — 3D creator platform prototype

An original Roblox-inspired prototype in Unity 2022.3.62f3. This project is independent and not affiliated with Roblox. The original LAST LIFT experience remains included.

## Offline prototype
- Platform home, local profile, avatar color selection, a playable featured experience, and a basic 3D world editor.
- Place blocks, platforms, spheres, cylinders and walls; stack objects; rotate the latest object; erase objects; save/load the local world; walk-test the creation.
- World and profile data are stored on the current device. Publishing, public discovery, accounts and multiplayer are not active.

## Open
1. Open this repository folder in Unity 2022.3.62f3.
2. Wait for scripts/import to finish. The platform scenes are generated by the editor tool when needed.
3. If scenes are missing, choose Tools → CREATORVERSE → Build Platform Prototype.
4. Open Assets/Scenes/CreatorVerseHome.unity and press Play.
5. Choose CREATE WORLD to open the builder, or PLAY LAST LIFT for the existing platform game.

## World editor controls
Choose a primitive, then click the floor or an existing object to place. Clicking an existing object stacks the next object. ROTATE turns the latest object; DELETE MODE removes clicked objects; HEIGHT +/- adjusts elevation; SAVE/LOAD stores one world on this device; TEST WORLD toggles a local walk test.

## Status
GitHub Actions validates source/configuration presence only. It does not prove Unity compiled, did a play test, or built an APK. Verify those in the Unity Editor. No backend secrets are needed for offline mode.
