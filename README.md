# LAST LIFT — Offline-first Unity 3D game

LAST LIFT is a mobile-first 3D platform/elevator challenge prototype, built to grow in small safe steps.

## Unity version
Open with Unity 2022.3.62f3 (the 2022.3 LTS editor).

## What is included
- A procedural first level with platforms, a moving lift, collectible coins, a laser hazard and a finish portal.
- Third-person movement, jump, follow camera and keyboard + touch controls.
- Main menu, profile editor, avatar skin picker, settings, pause, win and retry screens.
- Offline profile with display name, coins, best level and skin selection saved with PlayerPrefs.
- A small boundary between local profile storage and gameplay, intended to make a future cloud profile implementation easier.
- Existing character FBX files are retained at the repository root and also placed in Assets/Characters so Unity can import them.

## Open and play
1. Add this repository folder in Unity Hub and open it with Unity 2022.3.62f3.
2. Wait for Unity to import the FBX and compile scripts. The starter scene is generated automatically when the editor loads the project for the first time.
3. Open Assets/Scenes/LastLift_Level01.unity and press Play.
4. If the scene was not generated automatically, use Tools > LAST LIFT > Build First Level.
5. Keyboard: WASD / arrows to move, Space to jump. In the game view, touch controls are shown for mobile.

## Android build
Install Android Build Support (SDK, NDK and OpenJDK) from Unity Hub. In Unity, open File > Build Settings, select Android, choose Switch Platform, and build an APK. Test the APK on a real Android phone before release.

## Future online-ready direction
Gameplay reads a local profile contract instead of making network calls directly. A future cloud profile service, authentication, leaderboards and multiplayer can be added behind a separate interface. The current build does not have online accounts, matchmaking, ads, a backend or multiplayer enabled.

## Honest status
This repository contains a Unity project scaffold and a procedural level generator. The actual scene is generated by opening Unity because Unity serializes scene files and imports FBX assets in the editor. The repository update itself does not prove that Unity compiled the project or that an APK has been built; verify that in the Unity editor before release.
