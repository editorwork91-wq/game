# CreatorVerse roadmap

## Stage 0 — current offline prototype
- Home/catalog UI, local profile/avatar, world editor and one playable built-in experience.
- Local persistence and editor tools that generate scenes.
- No network dependency or fake online success states.

## Stage 1 — creator loop
- World library, thumbnails, undo/redo, object properties and touch-friendly controls.
- Build validation, spawn-point validation and low-end Android performance testing.

## Stage 2 — accounts/cloud
- Decide backend and schema before adding authentication.
- Cloud profile/world saves, safe publishing workflow and access controls.
- No service-role or server secrets in the client.

## Stage 3 — multiplayer
- Server-authoritative sessions, versioned world serialization, server validation and rate limits.
- Load tests, anti-cheat, reliable persistence and outage handling.

## Stage 4 — public creator platform
- Upload review, moderation/report/block systems, content filtering, creator attribution, licensing checks, quotas and abuse response.
- Consider marketplace/economy only after security, legal/accounting and operations are addressed.

The current project is only an offline vertical slice. It is not yet a scalable Roblox replacement.
